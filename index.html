Conceptos Clave de Intercambio de Datos entre Sistemas

API

Interfaz de Programación de Aplicaciones. Permite que diferentes software se comuniquen entre sí.

REST

Estilo arquitectónico para servicios web basado en HTTP, ideal para aplicaciones web modernas y escalables.

SOAP

Protocolo basado en XML, altamente estructurado y seguro, utilizado comúnmente en entornos empresariales.

JSON

Formato ligero de intercambio de datos basado en texto, fácil de leer y procesar por los navegadores.

XML

Lenguaje de marcado robusto y estructurado en etiquetas, tradicionalmente usado en sistemas corporativos.

GraphQL

Lenguaje de consulta para APIs creado por Meta, que permite solicitar exactamente los datos necesarios.
